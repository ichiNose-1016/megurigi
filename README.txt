MEGURIGI LP
============

■ 表示方法
1. ZIPを解凍します。
2. megurigi_lp フォルダ内の index.html をChrome / Safariで開きます。

■ 今回反映した修正
- メインビジュアルをチーズケーキ写真に変更
- キャッチコピーを「人とヒト。人とモノ。人と新しいセカイ。」に変更
- ギャラリー画像の縦横比・割り当て・トリミング位置を調整
- 出展者数を「全7名予定」に変更
- お問い合わせ先を megurigi.aozora@gmail.com に設定
- PC・スマートフォン両対応

■ 編集方法
- 文章・ページ構成：index.html
- 色・レイアウト・スマホ対応：style.css
- メニュー開閉・スクロール演出：script.js
- 写真・ロゴ：assets フォルダ

■ 公開前に確認する項目
- カフェの所在地・営業日・営業時間・メニュー価格
- イベントの最新情報、出展者情報、来場予約の要否
- 写真の掲載許可・利用範囲
- 公式Instagram・Threadsのリンク

■ 備考
Google Fontsの読み込みにはインターネット接続が必要です。
